# W02 程序级盲水印协议 v1

实际启动日期：2026-10-09；计划 W02 为 2026-10-19 至 2026-10-25。当前为探索性工程冻结，正式确认性协议仍以 W12 预注册为准。

候选是独立 Python 模块，提供 `embed(image, message, key) -> image` 与 `decode(attacked_image, key) -> message`。算法可自定义载体、编码、同步、提取数学关系；本协议不限定为 DCT/QIM。公开固定参数：RGB uint8，256×256，32-bit 载荷，16-byte 密钥。每张图像和每次试验由 evaluator 独立 RNG 生成消息与密钥，不能使用同一固定答案。输出尺寸、类型和载荷长度必须完全一致。

评价器先调用 embed，再分别施加 A0 与 A1 攻击，最后在独立子进程中调用 decode。decode 的进程输入只包含攻击后的 RGB 图像、密钥和固定公开协议；原图、原消息、攻击名称与参数真值只保留在 evaluator 父进程。候选进程不被传入数据文件路径。几何真值只供父进程诊断，不能作为候选输入。任一候选若尝试经接口读取隐藏字段，判无效。

质量门槛：A0 必须完整恢复 32 bit，并满足 PSNR ≥35 dB；否则该候选所有攻击分数均为 0。A1 指标分别报告 BER 与全消息成功率，不从不同候选拼接最佳结果。图像预处理为中心正方形裁剪，再用固定 Lanczos 缩放。攻击顺序、插值与填充在 `configs/attacks_v0.yaml` 固定。A2/A3 复合攻击在 W09 冻结，本版本不抢先宣称完成。

子进程分别执行 embed/decode，具有 5 秒超时；崩溃、缺失函数、输出形状/类型不符、非二进制载荷、失真超限一律标记失败并占用已提出候选的分母。当前运行器使用隔离进程与受控输入通道，但没有 Windows OS 级安全沙箱；恶意程序主动扫描本机文件系统仍是残余风险。W03 接入第三方生成代码前必须再完善文件系统限制或只在隔离容器/主机中运行。此限制不影响本周对“接口不传递原图/消息/真值”的契约测试。

D-search 用于生成期间评价，D-select 用于开发验证和选模，D-test 自当前起封存；仅在 W15 按预注册选模规则正式开启。三份清单及 SHA-256 在 `data/`，其中 D-test 逐图身份清单仅保留本机、被 Git 忽略；仓库只保存其 SHA-256 锚点与数量。不能把旧 Stage 1-8 已用 COCO 100 张或 Stage 7 已用 1000 张混入新盲测。数据来源为本机 COCO val2017；仅保存文件标识与哈希，不提交原图或权重。建清单时读取过 D-test 原始图像字节以计算 SHA-256 与 dHash；没有在 D-test 上评价水印候选或攻击。当前公开选择脚本加本机旧项目清单可重建 D-test 身份，故在 W03 将候选代码与这些输入物理隔离之前，不能声称对恶意候选保密。近重复检测目前使用缩略 dHash 距离阈值 5；通过不意味着语义上绝无近重复，W12 应复查。

基线冒烟使用两种不同数学结构：RGB 蓝通道位置键控 LSB 与 RGB 蓝通道分块 DCT/QIM。这两者只验证评价器支持多结构与盲提取，无新颖性或鲁棒性优越性主张。
