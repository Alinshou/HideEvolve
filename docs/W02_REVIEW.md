## 硬性验收 6 项

1. **两种结构共用 evaluator：** 6/6 次真实图像冒烟运行 `completed_valid`，完整记录在 `experiments/w02_smoke_20261009.json`。两种方法分别是空间 LSB 与分块频域 QIM，不是同一种结构的参数变体。
2. **无攻击盲提取：** 6/6 次 A0 全消息成功，BER 为 0；6/6 次 PSNR 超过 35 dB。对 JPEG/旋转/缩放有失败样本，已经保留，未宣称鲁棒性。
3. **消息与真值隔离：** decode 独立子进程请求字段固定为受攻击图像、密钥、载荷长度与操作标识；无原图、原消息、攻击 ID/参数。环境未携带 DeepSeek 密钥。文件访问审计拒绝测试候选读取旧项目原图；测试覆盖。
4. **失败记账：** 超时、显式崩溃、无攻击恢复失败、失真超限保留 `proposed=1` 且分数 0。失败不从分母消失。
5. **数据互斥：** 来源为 COCO val2017 本地 5000 张；先排除旧 PoC 100 张和 Stage 7 1000 张，再进行 D-search/D-select/D-test 确定性分配。三类共 1080 张互不重叠，均不与 1100 张旧图像重叠。建清单时采用 64-bit 灰度 dHash，距离≤5 的旧图/已选图候选将被拒绝；本次首批 1080 个候选中实际无触发。冻结列表不代表语义近重复风险为零。
6. **配置、版本和日志：** `configs/protocol_v1.yaml` 与 `configs/attacks_v0.yaml` 固定参数；`data/splits_v1_receipt.json` 含原始身份清单来源哈希及三份清单哈希；`experiments/w02_smoke_20261009.json` 保存每次运行、种子与候选代码哈希；`experiments/w02_contract_test_20261009.txt` 保存七项测试通过日志。本次均未使用 DeepSeek API，新增费用 0。

## 限制与下一道门

- 当前候选在 Windows 子进程运行，使用 Python 审计钩子拦截常见文件打开、目录枚举、网络与子进程行为；这不是完整的操作系统安全沙箱。恶意或绕过审计钩子的生成代码仍可能访问本机资源。W03 在接入模型生成代码之前，必须改用受限容器/独立主机，或建立同等强度的可信执行边界。此门槛尚未通过。正式盲测前还要将 D-test 身份与可重建其身份的来源清单一并隔离。
- 当前画质阈值 35 dB、RGB 256×256、32-bit 和 A1 强度是 W02 探索性工程设置，W12 正式预注册前须再复核。A2/A3 复合攻击在 W09 冻结，不能将本周的 A1 冒烟冒充困难任务结果。
- 两个冒烟基线在 A1 中均出现明显失败，说明评价器能记录失败，也说明目前没有鲁棒水印算法成绩；这些结果不构成 Agent 搜索优势证据。
- D-test 的授权、版权、语义近重复与源数据恢复应在正式盲测前复审。若源清单或旧使用范围出现具体新增冲突，建立新版本并暂停依赖原清单的尚未执行步骤。
